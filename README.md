# ZabonDon WebApp

Веб-версияи барномаи ZabonDon (омӯзиши забони русӣ): React Native Web (Expo) + TypeScript.

## Оғоз

```bash
npm install
npm run web      # http://localhost:8081
```

## Нашр

Бо ҳар push ба `main`, GitHub Actions сайтро месозад ва ба GitHub Pages мефиристад
(`Settings → Pages → Source: GitHub Actions`).
Сайт: https://yunusovshahriyor.github.io/ZabonDonWebApp/

Сохтани маҳаллӣ: `npx expo export --platform web` (папкаи `dist`).
